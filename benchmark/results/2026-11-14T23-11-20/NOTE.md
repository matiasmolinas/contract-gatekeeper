# Interrupted run

This run (revision 2, three arms) was started for three runs per arm. Run 1 completed for all three arms and its data is valid. The machine then went to sleep; when it woke up, the model calls of run 2 failed with timeouts, so the process was stopped. There is no `summary.md` here because the run never finished.

The complete revision-2 run is in the next results folder. The three `run1-*.json` files here are an extra, valid observation of the same configuration.
